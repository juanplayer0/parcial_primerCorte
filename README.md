# parcial
Este programa en C++ lo que hace es pedirle al usuario varios puntos (x, y) y luego calcula cual de todos tiene la mayor magnitud desde el origen (0,0). Basicamente usa la formula de la raiz cuadrada de x² + y² para cada punto y compara los resultados.

Se usa una estructura llamada Point para guardar los datos y una función aparte que se encarga de hacer el calculo y devolver el valor mas grande, tambien guarda el indice donde estaba ese punto.

El programa primero pregunta cuantos puntos se van a ingresar, despues los guarda en un arreglo y al final muestra el indice y la magnitud mayor encontrada.
